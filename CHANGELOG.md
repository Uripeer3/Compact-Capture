# Changelog

## 0.1.0 — release candidate

- Adds compact freehand, rectangle, arrow and highlighter annotation controls
  to GNOME 50's native Area and Screen screenshot workflows.
- Preserves GNOME ownership of capture, clipboard, storage, notifications,
  pointer composition and recording.
- Adds selection-first area capture, undo/redo, accessible hints, monitor-aware
  placement and bounded drawing work.
- Keeps Window capture, recording and empty annotations on GNOME's native path.
- Includes translations infrastructure, compatibility gating, privacy and
  troubleshooting documentation, and release/package verification.

Pixelate, blur, text and editable objects remain planned for Version 0.2.
